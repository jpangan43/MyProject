# Create Users

Simple step-by-step guide to create users in Microsoft Entra ID.

## Steps

### 1 – Create a new user

1. Go to **Users** → **All users** → **+ New user** → **Create new user**
2. Fill in the **Basics** tab:
   - **User principal name:** e.g. `itadministrator` @ `jasvasolutions.bid`
   - **Display name:** e.g. `IT Administrator`
   - **Password:** Auto-generate (or set manually)
   - **Account enabled:** checked
3. Click **Review + create** (or continue to Properties / Assignments if needed)

![Step 1](../extracted/Create-Users/Create%20Users/1.png)

---

### 2 – Confirm users are created

The new users appear in the **All users** list (e.g. CEO, Finance Manager, HR Manager, IT Administrator, Marketing Manager, Operations Manager, Sales Manager).

![Step 2](../extracted/Create-Users/Create%20Users/2.png)

---

## Notes

- Use the custom domain (e.g. `jasvasolutions.bid`) for the UPN.
- After creation, assign users to the appropriate security groups and roles.
