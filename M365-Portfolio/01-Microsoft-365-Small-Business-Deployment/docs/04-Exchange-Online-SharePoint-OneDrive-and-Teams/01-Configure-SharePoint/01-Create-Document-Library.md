# Create Document Library

Simple step-by-step guide to create a Policies document library in SharePoint.

## Steps

### 1 – Create Document Library (Policies)
Open the SharePoint site and start creating a new document library (Policies).

![Step 1](../extracted/DocLib/Create%20Document%20Library/1%20-%20Create%20Document%20Library%20%28Policies%29.png)

---

### 2 – Choose Blank Library
Select **Blank library**.

![Step 2](../extracted/DocLib/Create%20Document%20Library/2%20-%20Choose%20Blank%20Library.png)

---

### 3 – Name the Document Library
Enter the name (e.g. **Policies**) and create the library.

![Step 3](../extracted/DocLib/Create%20Document%20Library/3%20-%20Name%20the%20Document%20Library.png)

---

### 4 – Policies Library created
Confirm the Policies library is available (Company Policy folder).

![Step 4](../extracted/DocLib/Create%20Document%20Library/4%20-%20Policies%20Library%20%28Company%20Policy%20Folder%29.png)

---

## Notes

- Use a clear name such as **Policies** or **Company Policies**.
- Add folders and permission settings as needed after creation.
