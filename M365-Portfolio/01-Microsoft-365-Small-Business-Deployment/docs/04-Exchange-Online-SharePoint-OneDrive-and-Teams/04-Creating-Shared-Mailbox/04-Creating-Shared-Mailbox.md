# Creating Shared Mailbox

Simple step-by-step guide to create a shared mailbox and grant access.

## Steps

### 1 – Start creating the shared mailbox
In the Microsoft 365 / Exchange admin center, go to **Shared mailboxes** (or Recipients → Shared) and start the create wizard.

![Step 1](../extracted/Shared-Mailbox/Creating%20Shared%20Mailbox/1.png)

---

### 2 – Enter mailbox details
Provide the display name, email address, and other required details, then create the shared mailbox.

![Step 2](../extracted/Shared-Mailbox/Creating%20Shared%20Mailbox/2.png)

---

### 3 – Adding members to group
Add the users (or a group) who need access to the shared mailbox.

![Step 3](../extracted/Shared-Mailbox/Creating%20Shared%20Mailbox/3%20-%20Adding%20members%20to%20group.png)

---

### 4 – Give access and permission
Grant **Full Access** (and **Send As** if required) so members can open the mailbox and send from it.

![Step 4](../extracted/Shared-Mailbox/Creating%20Shared%20Mailbox/4%20-%20Give%20access%20and%20permission%20to%20shared%20mailbox.png)

---

## Notes

- Shared mailboxes do not require a license for the mailbox itself.
- Users need an Exchange Online license to access the shared mailbox.
- Prefer assigning a security group for easier membership management.
